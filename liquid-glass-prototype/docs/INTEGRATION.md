# Интеграция в FLauncher

1. Склонируйте оригинальный проект: `git clone https://gitlab.com/flauncher/flauncher.git`.
2. Скопируйте `lib/liquid_glass_tokens.dart` в каталог `lib/` проекта.
3. В существующем главном экране сохраните текущие провайдеры/сервисы получения приложений и категорий. Замените только визуальные контейнеры: оборачивайте карточки и панели в `LiquidGlassSurface`.
4. Поместите `LiquidGlassClock` в `Stack` главного экрана с `Alignment.topCenter`. Не добавляйте часы в верхний правый угол.
5. Для настроек используйте `LiquidGlassSettingsDrawer` поверх текущего экрана настроек. Передайте существующий экран настроек в `child`; `open` и `onClose` свяжите с состоянием страницы.
6. Подключите фокус карточек к существующей D-pad навигации FLauncher. Не заменяйте `FocusNode`, обработчики Enter/Back и каналы запуска приложений демонстрационными обработчиками из HTML.
7. Свяжите настройки accent/opacity/blur/spring со штатным хранилищем пользовательских настроек. В демонстрации эти значения хранятся только в состоянии страницы.
8. Проверьте на реальном Android TV: фокус с пульта, Back, масштабирование текста, производительность blur и поведение при разных разрешениях.

## Производительность
Backdrop blur на большом количестве одновременно видимых карточек может быть дорогим для слабых ТВ-приставок. Используйте blur преимущественно на крупных панелях/доке, ограничивайте число слоёв, избегайте вложенных BackdropFilter и предусмотрите режим Reduced Effects.

## Чего не делать
Не отключайте штатные Android intents, package discovery, Drift/SQLite, wallpaper provider или MediaSession. Это UI-слой, а не замена платформенной логики лаунчера.
